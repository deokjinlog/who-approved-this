# Aside 요청서 — 에이전트 고도화에 필요한 데이터

에이전트는 부품이 다 있는데 **검증할 데이터가 없어서 막힌 칸**이 셋이다. 우선순위 순.
각 요청은 그대로 복사해 Aside 에 넣으면 된다. 공통 조건은 맨 아래.

| # | 막힌 곳 | 지금 상태 | 이 데이터로 풀리는 것 |
|---|---|---|---|
| A | 전결 금액 구간 | 20건 최종 결재가 조직마다 1가지 → 분기 **0회 검증** | 결재선 에이전트의 ③단계 |
| B | 초안 템플릿 | 20건에서 귀납된 템플릿이 **회계지출 1종뿐** | 초안 칸 구조 |
| C | 첨부 | 0건 → 초안 금액 칸 전부 `[첨부 필요]` | 요약 템플릿, 초안 첨부 칸 |

---

## A. 정찰 → 한 기관 집중 (가장 중요)

```
정보공개포털에서 "결재 종점이 갈리는 기관" 하나를 찾아줘. 두 단계로.

1단계 정찰 (먼저 이것만, 싸다)
  후보 기관 3곳에서 결재문서 원문 PDF를 각 10건씩 받아, PDF 하단(또는 상단) 결재란의
  **최종 결재자 직위**만 세서 표로 줘. 이름은 적지 마.
  후보 (다른 곳이 더 나으면 바꿔도 됨):
    - 경기도 본청의 계약·재무 관련 과 (예: 회계과)
    - 경기도교육청 산하 교육지원청 1곳
    - 경기도 내 시·군 1곳의 계약·공사 관련 과
  판정 기준: 10건 중 최종 결재 직위가 **2가지 이상**(예: 과장 전결 / 국장 / 기관장)이면 통과.
  전부 같으면 탈락. 전결·대결 표기가 있는지도 같이 적어줘.

2단계 (통과한 기관 1곳만)
  - 결재문서 30건 더 (유형이 섞이게: 지출·계약·계획·결과보고·알림). 금액이 작은 것과 큰 것이 섞이게.
  - 그 기관의 위임전결규정(사무전결처리규칙) 원문 + **별표 전체**. 자치법규정보시스템(elis.go.kr)
    또는 기관 홈페이지. 별표에 금액 구간(예: "5천만원 이상")이 있는지 확인해서 적어줘.
  - 그 기관의 조직도 + 직원 담당업무 안내(홈페이지 "조직안내/직원안내"). 담당업무 열이 있는 페이지.
  저장: artifacts/opengokr_org/ (결재문서), artifacts/rules_org/ (규정·조직도).
  metadata.tsv 헤더는 기존과 같게 + "실제조직" 열. sources.md 에 각 파일의 출처 URL·확인일.
```

**왜 이 순서인가** — 규정·조직도를 아무리 잘 모아도 그 기관 문서의 결재 종점이 한 가지면
전결표가 작동하는지 검증할 수 없다(지금 20건이 정확히 그 상태다). 그 판정은 문서 10건이면 끝난다.

## B. 서식(템플릿)

```
A에서 고른 기관(없으면 경기도·경기도서관)의 공문 서식 원본을 받아줘.
  - 지출결의(또는 지출 품의), 계약 요청, 사업계획 보고, 결과 보고, 알림·통보 공문 서식
  - hwp/hwpx 원본 우선, 없으면 pdf. 기관 서식 자료실·자치법규 별지서식 모두 봐줘.
  - 서식마다 "항목 이름 목록"(예: 1. 목적 2. 추진내용 …)을 sources.md 에 적어줘.
저장: artifacts/templates_org/
없으면 "없음"과 확인한 경로. 억지로 채우지 마.
```

## C. 첨부가 있는 결재문서

```
정보공개포털에서 붙임파일이 **실제로 열리는** 결재문서 10건. A 기관 우선, 부족하면 경기도.
  - 붙임 확장자가 섞이게: xlsx 3, pdf 3, hwp/hwpx 2, 이미지 2 (못 채우면 있는 대로)
  - 지출 문서를 최소 3건 포함 (금액·산출내역이 첨부에 있는 것)
  - 저장: artifacts/opengokr_attach/{저장파일명}/ 에 본문.pdf + 붙임 원본
  - metadata.tsv 에 "붙임파일목록" 열 (파일명;확장자;크기, 세미콜론 구분)
  - download_recipe.md 에 붙임 다운로드가 본문과 다른 요청인지 기록
끝나면 확장자별 건수와 용량 분포.
```

## 공통 조건 (모든 요청)

- 요청 간격 5초 이상, 로그인 금지, 429 나오면 멈추고 알려줘
- 원문은 로컬에만. 보고서·표에 **사람 이름 적지 마** (직위로)
- 기관 거부("시스템 점검 등으로 열람 불가")는 제외하고 사유만 기록
- 공개 목록에 없는 건 억지로 채우지 말고 "없음"
